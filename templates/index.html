🤖 Model Architecture
CLIP (Contrastive Language-Image Pre-training)

OpenAI's multimodal learning model trained on 400M image-text pairs from the internet. It learns visual representations by contrasting actual text descriptions with incorrect ones.

Architecture: ViT-B/32

Vision Transformer backbone with 32x32 patch size. Contains 86M parameters optimized for efficient processing on both CPU and GPU.

Zero-Shot Classification

No fine-tuning required. The model classifies images by comparing visual features with text prompts like "a photo of a [ethnicity] person".

Dataset

RFW (Racial Faces in the Wild) - 55,623 face images from 4 ethnicities for evaluation and validation.

Performance Metrics

✓ Accuracy: 90.58%
✓ F1-Score: 0.905
✓ Inference Speed: ~50ms per image
✓ Model Size: 352 MB

⚠️ Important Disclaimer

This model is for educational and research purposes. Ethnicity classification inherently involves biases and limitations. Always consider cultural, genetic, and individual variations. Never use for discriminatory purposes.
